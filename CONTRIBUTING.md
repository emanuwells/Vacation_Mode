# Contribuir

## Fluxo

1. Ler `.agents/AGENTS.md` se a alteração for assistida por IA.
2. Criar uma branch dedicada.
3. Fazer alterações pequenas e focadas.
4. Executar as validações de `COMMANDS.md`.
5. Atualizar documentação, `.agents/state/` e changelog quando aplicável.
6. Rever o diff antes de integrar.

## Commits

Usar mensagens claras e imperativas, por exemplo:

- `feat: adicionar endpoint de estado`
- `fix: corrigir validação de datas`
- `docs: atualizar instruções de instalação`
- `chore: atualizar sistema WELLS`

## Pull requests

Incluir objetivo, alterações principais, validações, riscos e rollback.
